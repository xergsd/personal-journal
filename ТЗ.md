# Главная идея продукта
Личный буллет-джорнал на ноутбуке. В нём два раздела:
- Дневник — чистая страница для свободных мыслей.
- Трекер — задачи, привычки, время и цели.
Во время письма на экране только текст. Трекер помогает, но не давит.

# Платформа
- Работает локально на моём Mac: FastAPI + SQLite. Фронтенд — HTML, CSS
  и JavaScript без фреймворков, раздаётся самим FastAPI.
- Открывается в браузере отдельным окном, сервер запускается
  автоматически при включении ноутбука.
- Все данные хранятся только на моём компьютере, в интернет ничего

# Функции

## 1. Дневник
- Запись начинается с заголовка. Его я пишу сам, он обязателен.
- Цитата дня: над заголовком — цитата великого человека, чтобы
  вдохновить или поддержать. Утром — вдохновляющая, вечером —
  поддерживающая. В течение дня цитата не меняется. Когда я начинаю
  писать, цитата сворачивается в одну строку.
- Цитаты хранятся в локальном файле (JSON): текст на русском, автор,
  тип (утро / вечер). Минимум 100 цитат с проверенным авторством —
  никаких выдуманных или приписанных.
- Письмо во весь экран, только текст, без отвлекающих элементов.
- Тип записи: утро / вечер / свободная. Определяется по времени суток,
  можно сменить вручную.
- Автосохранение: черновик пишется в браузер при каждом нажатии клавиши
  и отправляется на сервер раз в несколько секунд. Индикатор «сохранено»
  едва заметен. При закрытии вкладки ничего не теряется.
- После записи — короткий экран закрытия: настроение 1–10, энергия
  1–10, теги. Его можно пропустить.
- Теги: базовый набор (учёба, работа, здоровье, отношения, проекты)
  плюс свои.
- Записи можно перечитывать и редактировать.

## 2. Трекер
- Задачи на день: список с галочками. Одну задачу можно отметить
  звёздочкой как главную задачу дня. Невыполненные задачи можно одним
  нажатием перенести на завтра.
- Привычки: я сам создаю список (например, сон 7+ ч, спорт, чтение,
  английский). Отметка — галочка или число (часы, минуты). Вид — сетка
  с кружками за неделю, как в бумажном буллет-джорнале.
- Учёт времени: вручную, в конце дня указываю, сколько ушло на каждую
  категорию (учёба, проекты, отдых и т. д.). Категории настраиваются.
  Таймера нет.
- Цели на неделю: 3–5 целей, в конце недели отмечаются как выполненные.

## 3. Календарь и архив
- Календарь месяца: дни с записями отмечены, цвет дня отражает среднее
  настроение.
- Нажатие на день открывает страницу этого дня: записи, задачи,
  привычки, время.
- Таблица всех записей: дата, тип, заголовок, настроение, энергия,
  теги. Фильтры по дате, тегу и типу, поиск по тексту.

## 4. Статистика
- График настроения и энергии (неделя / месяц / всё время).
- Процент выполненных главных задач за неделю и месяц.
- Привычки: процент выполнения и серия дней подряд. Серия без давления:
  пропуск не выглядит как провал.
- Время: распределение по категориям за неделю и месяц.
- Связи: например, среднее настроение в дни, когда привычка «сон»
  выполнена, и в дни, когда нет.
- Самые частые теги и среднее настроение по каждому тегу.

## 5. Недельный обзор
- Итоги недели: средние настроение и энергия, лучший и самый тяжёлый
  день, выполнение целей, главных задач и привычек, время по
  категориям, частые теги.
- Поля «что я понял» и «что меняю на следующей неделе».

## 6. Напоминания
- Через Google Calendar: два повторяющихся события (утро и вечер)
  со ссылкой, которая открывает новую запись нужного типа,
  например http://localhost:8000/new?type=morning.
- В приложении для этого нужны только такие ссылки, отдельный код
  напоминаний не нужен.

# Модель данных
- Entry: id, created_at, updated_at, тип (morning / evening / free),
  заголовок, текст, настроение, энергия, теги.
- Tag: id, название, цвет.
- Task: id, дата, текст, выполнена, главная (bool), перенесена из (id).
- Habit: id, название, тип отметки (галочка / число), единица,
  цель, активна.
- HabitLog: id, habit_id, дата, значение.
- TimeCategory: id, название, цвет.
- TimeLog: id, дата, category_id, минуты.
- WeeklyGoal: id, неделя, текст, выполнена.
- WeeklyReview: неделя, что я понял, что меняю.
- Settings: тема, PIN.

# Дизайн — буллет-джорнал
- Фон — бумага в точку (dot grid), тёплый белый.
- Заголовки рукописным шрифтом Caveat, текст записей — Lora, крупно
  и с большим межстрочным интервалом.
- Акцент — синие чернила перьевой ручки. Заголовок записи выделен
  жёлтым маркером.
- Привычки — кружки от руки, задачи — квадратики-чекбоксы.
- Цитата дня — курсивом, тихо, не спорит с заголовком.
- Много воздуха, никаких ярких цветов и тяжёлых теней.
- Тёмная тема — тёмный bujo: тёмная бумага, еле заметные точки,
  светло-голубые чернила, приглушённый маркер. Включается вручную
  или автоматически вечером.
- Слева навигация: Дневник · Трекер · Статистика · Неделя.
- Приватность: вход по PIN.
- Макет стиля: https://claude.ai/artifact/DPjPyN2VVkqiRrv9Z3XA5r
